## 合成と確認

モデルは `mlx-community/Qwen3-TTS-12Hz-0.6B-Base-4bit`。参照音声は、前回の一文読み直しで生成したBGMなしのJhenny音声6.53秒です。2文は各1回生成し、再生速度とピッチは変更していません。聞き比べやすいよう、候補それぞれの音量を対応する元音声に合わせています。

Whisperによる認識では1文目は本文どおり、2文目はQDEFをQDFと表記して認識しました。発声用原稿は「キューデフ」です。音声認識だけでは「にー」の長さや声の一致までは判断できません。

WAV 2本と比較MP4の全編デコードを確認しました。比較動画は1280×720、24fpsです。声質・発音・前後のつながりの最終判断は試聴待ちです。
