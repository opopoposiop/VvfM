## 素材と演出

- シナリオの画像10点と、指定された `demo01.mp4` / `demo02.mp4` を使用しました。デモは通常速度のまま切り出しています。
- 参考動画 `いつものMacで、気軽にMMD体験.mp4` から、白い紙面、手描き風の線、淡い色とマーカーによる強調を参考にしました。参考動画の映像・音声は本編に流用していません。
- 画面写真には必要に応じてトリミングや緩やかな拡大を施し、ボーンの数値とギズモ、モーフのキーと波形、DoF設定を見せています。
- 未収録の読み込み・保存操作は説明図で示しています。操作の実録や、未撮影の効果ON/OFF比較としては扱っていません。
- デモの入力映像は1280×720です。1080pの画面内に配置しており、元素材以上の細部を復元したものではありません。
- 技術説明ではCPU/GPUの役割、PMX 2.1対応、Bullet 3.25ネイティブ／2.75互換を紹介しています。使用したシーンのモデルはPMX 2.0である旨も表示しています。性能測定・互換性認証を示す動画ではありません。

## 音声

ナレーションは **HeyGenのJhennyによるAI音声**です。声IDは `9530fac2d1f148f8b57b51b783b0df13`、承認された `heygen_voice` エンジン（結果のエンジン表記はOrca）を使用しました。APIの生成要求と結果を `source/heygen-*.json` に保存しています。

生成した音声を場面ごとに配置し、原則0.9倍の速度で整えました。場面06は末尾の読み落としを自動音声認識で検出したため、同じJhennyで生成し直した音声に置き換えています。元音声・補正音声・最終配置後の自動認識結果を `checks/` に保存しました。認識結果には固有名詞の誤認識が含まれるため、字幕本文はシナリオの原文を保持しています。

BGMは、この動画向けに作成した軽いインストゥルメンタルです。説明中は音量を下げています。デモ元の楽曲ではありません。BGMなし版にも同じJhennyナレーションが入り、ナレーションの音量は両版で揃えています。

## 編集用データ

- `composition/index.html`：HyperFramesの編集可能な構成。13場面、35カット。
- `source/build_composition.py`：画像・映像・字幕を構成するスクリプト。
- `source/scenes.json` / `source/edit-decision-list.json`：場面とカット割り。
- `source/audio-alignment.json` / `source/captions.json`：ナレーションと字幕の時刻。
- `source/create_bgm.py` / `source/mix_audio.py`：BGMと音声ミックス。
- `source/finalize_delivery.py`：2版の出力と媒体検証。
- `source/source-manifest.json`：入力素材のSHA-256。
- `checks/production-files-sha256.json`：制作データのSHA-256。

## 検証範囲

最終MP4それぞれの全フレーム・全音声をデコードし、長さ、解像度、フレーム数、音声形式、開始時刻、音量を確認済みです。両版の映像ストリームが一致すること、字幕38件が原文と一致して時刻の重複や場面外へのはみ出しがないことも検証済みです。結果の数値は `checks/delivery-validation.json` に保存しました。

表示確認は代表時刻の画像と13場面の一覧を使用しています。レイアウト検査で示された左端の音符のはみ出しは装飾として意図したもので、本文・字幕の欠けではありません。全編を人が実聴・実視聴したという確認は含みません。
