## 調整結果

| 指標 | 前版 | 調整版 |
|---|---:|---:|
| 文単位の平均テンポ | 5.23〜9.38拍/秒 | 7.50拍/秒 |
| 各文の中央音程 | 173〜266Hz | 212〜217Hz |
| 全編の有声音程・中央90% | 135〜325Hz | 185〜248Hz |
| 動画の長さ | 3分25秒 | 3分25秒 |

テンポは読みの拍数（モーラ数）÷文の長さでそろえています。一音ずつを強制的に同じ長さにする処理ではなく、文単位の平均速度を一定にしたものです。

音程は215Hzを中心に、上限・下限が約181〜256Hzになる滑らかな変換を用いて、抑揚の幅を圧縮しました。表の音程は有声部分を再測定した分位点であり、全サンプルの周波数を保証する値ではありません。無声子音や無音は音程範囲の対象外です。

元の文を連続した音声のまま処理しています。語句の差し替え、言い換え、削除、単語のつぎはぎはしていません。音量は一定ゲインで調整し、接続部に4msのフェードを付けています。

## 保持した内容

映像ストリーム、字幕の文字・表示時刻、イラスト、場面の時刻、チャプター、総尺は前版のままです。テンポをそろえるため文の開始位置と間を調整しており、字幕に対する音声のずれは最大約0.44秒前／0.40秒後です。各文は対応する場面内に収まり、音声の重なりはありません。

BGMは前版の「BGMありPCM − ナレーションPCM」を保持し、全サンプルで差分の一致を確認しています。この一致はAAC圧縮前のWAVに対するものです。元版のファイルは変更していません。
