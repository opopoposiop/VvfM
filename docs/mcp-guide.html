CODEX INTEGRATION

VMD Viewer for Mac MCP はじめての操作マニュアル

対象：公開版 v0.59.19
必要なもの：M2以降のMac・macOS 14以降・同じMacで動くCodex CLI

MCPは、Codexが起動中のVMD Viewer for Mac（VvfM）に作品の状態を問い合わせるための接続です。「120Fの顔を見せて」「このカットだけカメラを少し引いたらどうなる？」と日本語で頼めます。まずは作品を変えずに見て、気に入った変更だけを登録します。

1. Macで接続する

  1. VvfM v0.59.19を「アプリケーション」フォルダに入れて起動します。練習用の作品を開き、再生を止め、モデルを1体選択します。
  2. VvfMの 設定 → 一般 → 外部連携 → Codexとの共有 をONにします。初回はポーズ・カメラ・材質の変更許可をすべてOFFにしておきます。
  3. 同じMac・同じmacOSログインユーザーで「ターミナル」を開き、Codex CLIに次の接続先を登録します。
codex mcp add vmd-viewer -- "/Applications/VMD Viewer.app/Contents/Helpers/vmd-viewer-mcp"

アプリを別の場所に置いた場合は、引用符の中を実際のヘルパーの絶対パスに変更します。Codexをすでに開いている場合は、登録後に起動し直します。この接続手順はMac上で動くCodex CLI用です。Windows・Web・リモート環境から直接接続する手順ではありません。

共有前に：アプリへの接続自体は同じMac内に限られますが、取得したモデル名などの表示情報やプレビュー画像はCodexのモデル処理に渡る場合があります。初回は公開可能な練習用素材を使ってください。

2. 作品を変更せずに見る

Codexに次のどれかを貼り付けます。最初の依頼で、返ってきたモデルとコマがVvfMの画面と合っていれば接続できています。

やりたいことCodexへの依頼例
接続を確かめるVvfMのMCPで、選択中のモデルと現在のシーンフレームを教えて。編集・保存はしないで。
指定のコマを見るシーンの120Fを、選択中のVMDカメラで1枚見せて。カメラモーションがなければ現在の構図で。再生位置は変えないで。
書き出しの設定を点検する動画書き出し画面に入力した設定を調べて。開始できない理由と注意点を分けて。実際には出力しないで。

シーンFは作品全体の時刻です。VMDの30F/秒を基準にするため、120Fは4秒です。動画を60fpsで書き出す設定でも、この指定は変わりません。作品が短いときは範囲内のコマを選びます。単独コマのプレビューでは、前のフレームの描画結果を使う効果の見え方が連続再生と異なることがあります。

書き出しの点検は、画面を開いていれば入力中の設定を確認します。点検で警告がなくても、保存先への書き込みや動画変換の成功までは確かめられません。

3. 笑顔を試して 確認後に登録する

練習では作品を別名で保存してから始めます。笑顔のモーフがあるモデルを選び、再生を止めます。モーフ名が分からないときは、先に「選択中のモデルにある笑顔のモーフ名を確認して」と頼みます。

候補を作る

選択中のモデルで、シーン120Fから笑い始め、126Fで笑顔を70%、138Fで元の表情に戻る候補を作って。顔の拡大で編集前と候補を並べて、追加・更新するキーも教えて。まだ登録・保存はしないで。

実際のモーフ名やコマに置き換えます。開始と終了はそれぞれのコマの元の表情が基準です。区間内に別のキーがある場合はそのまま残るので、ピークだけでなく前後の表情も確認します。

採用する

  1. 対象モデル・モーフ名・コマ番号・画像を確認します。変更したいときは候補を作り直し、もう一度見比べます。
  2. 採用するときだけ、VvfMで ポーズのキー登録を許可 をONにします。
  3. Codexに「いま確認した候補だけ登録して。保存はしないで」と依頼します。
  4. VvfMで前後を再生します。この表情の登録は1回のUndoで戻せます。残す場合はVvfMの画面から保存します。

別の練習例として、すでにあるまばたきのキーを使って「100〜108Fのまばたきキーを、重みと間隔を保って2F早める候補を見せて」と頼めます。移動先に別のキーがある場合は、時刻を見直します。

4. 目的別の頼み方と許可

目的依頼例採用時に使う設定
上半身のポーズ135Fで本人の右肘を少し上げた候補を、元と見比べたいポーズのキー登録を許可
足滑りの補正15〜35Fで左足が滑るか調べて。補正候補があれば足元の前後を並べてポーズのキー登録を許可
カメラ構図の調整120Fで手が切れないようカメラを少し引いて、元の構図と比べてカメラのキー登録を許可
材質の表示切替前髪と髪飾りを非表示にした候補を、同じコマで見比べたい材質の表示変更を許可

候補を見るだけなら、表の許可はOFFのままです。 足のターンは意図した動きでも滑りの候補になる場合があります。カメラの余白も骨の位置を基準に調べるため、指先や髪先まで入っているかは画像で確認します。材質の表示を採用しても、元のPMXファイルは書き換えず、そのモデル個体のプロジェクト設定を変更します。

5. つながらない・登録できないとき

  • 「Codexとの共有」が見つからない：VvfMのバージョンを確認します。公開版v0.58.29にはこの機能はありません。
  • 「接続先が見つからない」：VvfMが起動中か、共有がONか、Codexが同じMac・同じログインユーザーで動いているかを確認します。アプリの移動や改名後は登録時のパスも確認します。
  • 複数のViewerが見つかる：まず対象のVvfMだけで共有をONにします。
  • モデルやコマが違う：作品を切り替えたときは現在の作品から照会し直します。同名のモデルが複数あれば、VvfMで対象を選択してから依頼します。
  • 候補を登録できない：再生を止め、目的に合う許可を確認します。プレビュー後に作品や編集状態を変えた場合は、候補を作り直して比較してから登録します。

作業の終わり：必要な変更をVvfMの画面で保存し、「Codexとの共有」をOFFにするか、VvfMを終了します。編集許可は共有終了・次回起動時にOFFに戻ります。
