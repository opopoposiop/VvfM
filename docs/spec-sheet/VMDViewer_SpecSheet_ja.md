# VMD Viewer for Mac スペックシート

**基準日: 2026-10-28（日本時間） | 保存済みRelease: v0.57.22 / build495**

PMXモデルとVMDモーションの再生・編集・レンダリングを行うmacOSアプリ。複数モデル、音声・動画の同期表示、物理演算、材質調整、モーション保存、動画書き出しに対応します。

> 本資料は、2026-10-28に開発側でコードと仕様書を照合したスペックシートの公開用版です。全機能の実機合格や処理性能を保証する資料ではありません。保存済みRelease495と開発中の変更は別の検証候補です。VvfMへの文書追加に伴うアプリのbuild・テスト・実機測定は実施していません。

## 2. 対応形式

| 分類 | 形式 | 用途・条件 |
| --- | --- | --- |
| モデル | .pmx | PMX 2.0 / 2.1、参照テクスチャ。複数モデル・ステージを配置。 |
| モーション | .vmd | ボーン / モーフ / カメラ / 照明 / セルフシャドウ / 表示・IKを読込・保持。編集内容の再保存に対応。 |
| 音声 | .wav / .m4a | 再生・波形表示。M4Aは1音声トラック、mono / stereoのAAC-LC・ALAC（システムが復号できるもの）。 |
| 入力動画 | .mov / .mp4 / .m4v | screen.bmp材質・指定材質または背景へ投影。利用可能なデコーダーに依存。 |
| ポーズ | .vpd | 指ポーズライブラリへ読込。左手・右手・両手・選択ボーンへ適用。 |
| エフェクト | .fxdayo | 既知ソース用Metal adapter、または条件を満たす限定原文実行profileで利用。 |
| DoF・照明 | .dofvmd | DoFと背景色・環境光色・平行光源色・方向のキーを読込・保存。 |
| プロジェクト | .vmdviewer | 素材・設定を同梱したZIP形式で保存・復元。旧directory packageの読込に対応。 |

動画の音声ミックスは対応仕様に含めず、動画書出しの音声入力はシーンに読み込んだWAV / M4Aです。VPDは読込・適用用で、VPD出力を記載したものではありません。

## 3. 再生・時計

| 対象 | 仕様 |
| --- | --- |
| VMD時刻 | 30 frame/s基準。描画周期とは独立し、小数フレームを補間。 |
| 描画設定 | 24 fps固定 / 30 fps固定 / 60 fps上限 / 無制限（画面の更新上限内）。 |
| 物理演算 | 60 / 120 / 180 / 240 Hzの固定ステップ。 |
| 操作 | 再生・停止、コマ送り、数値フレーム移動、スクラブ、範囲ループ。 |

上記fps / Hzは時計・設定の仕様で、実表示速度や性能測定値ではありません。

## 4. 編集・保存

| 機能 | 仕様 |
| --- | --- |
| モデル管理 | 追加・複製・入替・削除、表示・ロック、描画順、位置・回転・倍率、フレームオフセット、モデル別VMD割当。 |
| キー・タイムライン | ボーン / モーフ / カメラの登録・更新・削除、複数選択、移動、コピー・貼付、1フレーム挿入・削除、Undo / Redo、音声波形。 |
| ボーン・指・レイヤー | 複数ボーン、XYZギズモ、ローカル / グローバル編集、初期値・左右反転、指の握り・開き・親指曲げ、追加ボーンレイヤー。 |
| 補間・カメラ | ボーン4 / カメラ6チャンネルのBezier補間編集。独立カメラ1 / 2、透視 / 正投影、VMDカメラと自由視点の切替。 |
| 表情・自動生成 | モーフ値の一括編集、カメラ目線の両目キー生成・校正、ランダムまばたき生成。候補の確認・適用に対応。 |
| 口パク | 日本語5母音のキー生成。音声から仮生成し、歌詞・読みで再解析。手入力・下書きJSON・候補比較・明示適用に対応。外部解析環境は対応条件欄参照。 |
| 保存 | プロジェクトの上書き・別名保存。VMDはボーン / モーフ・フレーム範囲を選択保存。追加レイヤーは誤差検査付きで標準VMDへ合成出力。 |

未登録のボーン・モーフ・IK編集がある場合、保存・書出しの前に登録または取消が必要です。プロジェクトは素材や編集構造を保持し、通常VMDにはプロジェクト固有の構造をそのまま格納しません。

## 5. 描画・物理

| 機能 | 仕様 |
| --- | --- |
| 描画方式 | Metal、ToonShader（軽量）、ToonShader（高品質）。高品質はHDR中間描画、PMXエッジ、Diffusion、RimLight、Bloom、AO、Tonemapper。 |
| AA・被写界深度 | OFF / FXAA / TAA / MetalFXの排他選択。DoFの焦点・F値・ボケ量、モデル / ボーンへの焦点追従、DoFキーに対応。 |
| 材質・照明 | 標準材質 / PBR / Rhinestone、Holographic、画像・汎用ノードの配線。背景色・透明背景、環境光、平行光源、地面影・セルフシャドウ。 |
| スキニング・モーフ | BDEF1 / 2 / 4、SDEF、QDEF。頂点・UV・材質・ボーン、グループ / フリップ、物理インパルスモーフを評価。 |
| 物理 | Bullet 3.25ネイティブ / 2.75互換モード。Joint 0-5、TriMesh / Rope軟体、外部親、モデル間衝突。ON / OFF・リセット、重力・応答調整。 |
| 動画・表示補助 | 動画の開始位置・offset・loop・投影先を設定。グリッド、ワイヤーフレーム、ボーン・剛体・ジョイント表示、編集UIを隠す全画面。 |

Bulletの2.75互換モードも、実行するエンジンは同梱3.25です。2.75バイナリの切替やMMDとの完全一致を意味しません。Holographic / RhinestoneはMetal近似で、Holographicの半透明部分・鏡面内部への効果は対応範囲外です。

既知ソース用adapterの主な対象はMobFesPenlight_3、MMDayo_SSR、beam、Cracker、ikHolographicです。原文実行の限定profileにはHQ Toon・FrameTime・透視投影・不透明出力などの条件があり、対応可否は素材・構成ごとに判定します。

## 6. 動画書出し

| UI上のコーデック | コンテナ | 背景・アルファ |
| --- | --- | --- |
| H.264 | MP4 / MOV | 不透明 |
| HEVC | MP4 / MOV | 不透明 |
| ProRes 444 | MOV | アルファなし（ap4h） |
| ProRes 4444 | MOV | 透過 / 背景色を選択（ap4h） |
| ProRes 4444 XQ | MOV | 透過 / 背景色を選択（ap4x） |

「ProRes 444」はApple ProRes 4444（ap4h）をアルファなしで保存するアプリ内の表示名です。内部HDR描画やProResの格納形式から、出力がHDRまたは10 / 12-bit入力であるとは解釈しません。

| 項目 | 仕様 |
| --- | --- |
| 解像度 | 1280×720 / 1920×1080 / 3840×2160。カスタムは縦横とも2以上の偶数（GPU・エンコーダーの制約内）。 |
| 出力fps | 23.98（24000/1001）/ 24 / 29.97（30000/1001）/ 30 / 59.94（60000/1001）/ 60。カスタム1-240 fps。 |
| 色・音声 | SDR Rec.709、writer入力は8-bit BGRA。音声を含める場合はシーンのWAV / M4Aを指定範囲でtrimし、AAC-LC 48 kHz / 256 kbps設定で格納。 |
| 評価・操作 | VMD 30 fps基準の区間指定。専用オフスクリーン評価で全物理ステップを計算。進捗・取消・上書きに対応し、保存確定後に完了表示。 |
| 保存先 | ローカル・NASへ書出し。保存先フォルダーの一時ファイルから確定。対応コーデック・寸法は実行環境で判定。 |

透過出力ではMetalFX選択時にTAAを使用します。effectの対応条件により出力できない組合せは事前に拒否します。NASの確定方法はファイルシステムの機能に依存し、排他的rename非対応先での他プロセスとの同名競合は別条件です。

## 7. 制限・対応条件

| 項目 | 条件 |
| --- | --- |
| 互換性 | MMD / MMEの厳密な画像・物理一致は未検証。PMX 2.1の全機能対応ではなく、PMX編集・再書出し、追加UV2-4の汎用shader入力は未対応。 |
| エフェクト | 任意の.fx / .fxdayoを無条件に実行する仕様ではない。既知のSSR・beam・Cracker・Holographic等も版・構成条件がある。透過出力を拒否する効果がある。 |
| 口パク解析 | 仮生成はwhisper.cpp＋多言語モデル＋MFA、再解析はMFAと日本語モデルを別途設定。自動ボーカル分離・モデル自動取得は未実装。全母音を試聴・確認して採用する。 |
| 性能・検証 | 描画fpsは設定値であり、モデル数・頂点数・メモリの保証上限は未規定。33 ms応答目標・安定60 fpsは未受入。build495の正式性能・厳密音声同期・10分耐久・全codec / 4K / 全尺条件は未検証。 |
| 配布・運用 | 保存済みReleaseはアドホック署名版で、未公証・未配布として記録。自動更新・Autosave・外部参照の再リンクは未実装。OS宣言下限14での全面動作確認は未完了。 |

自動口パクの基準環境はMFA 3.4.3と日本語モデルです。原音と分離音の開始時刻・全長の一致は利用者が確認します。分離音ファイル、whisper.cpp / MFAの実行環境・モデルはプロジェクトの自己完結保存に含めません。

## 8. データ形式上の上限・補足

| 対象 | 上限・保存仕様 |
| --- | --- |
| VMD codec | ボーン / モーフ / カメラ / 照明 / セルフシャドウ / IKフレームは各20,000,000件。IK状態も1フレームあたり20,000,000件。フレーム番号は0-4,294,967,295。 |
| レイヤーのVMD合成 | 追加生成キー2,000,000件まで。合成誤差検査を通過した候補を保存。物理ベイクではない。 |
| DoF・照明キー | 合算100,000キー、16 MiBまで。照明VMDの取込時にも展開後のキー数制限を適用。 |
| VPD | 1ファイル16 MiB / 100,000 recordsまで。UTF-8 / Shift_JISの標準的なボーン姿勢。 |
| プロジェクト | ZIP container v1、現行manifest schema42。必要reader版は使用機能により変わる。 |

形式上の上限は、その件数・容量での処理速度や実機動作を保証する値ではありません。実用上の上限は入力と機器資源に依存します。
