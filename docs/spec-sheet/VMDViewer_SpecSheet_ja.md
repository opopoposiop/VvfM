# VMD Viewer for Mac スペックシート

**配布版 v0.59.19／build695　•　2026年11月23日**

PMXモデルとVMDモーションを読み込み、ボーン・表情・カメラを編集して、音声付きの動画を書き出せるMac用アプリです。Codexを接続すると、編集中の作品でポーズや構図の候補を比較できます。

[配布版をダウンロード](https://github.com/opopoposiop/VvfM/releases/download/v0.59.19/VMD.Viewer.app.zip) ｜ [リリース詳細](https://github.com/opopoposiop/VvfM/releases/tag/v0.59.19) ｜ [PDF版](VMDViewer_SpecSheet_ja.pdf)

## 2. 対応形式

| 分類 | 形式 | 用途・条件 |
| --- | --- | --- |
| モデル | .pmx | PMX 2.0 / 2.1、参照テクスチャ。複数モデル・ステージを配置。 |
| モーション | .vmd | ボーン / モーフ / カメラ / 照明 / セルフシャドウ / 表示・IKを読み込み・保持。編集内容の再保存に対応。 |
| 音声 | .wav / .m4a | 再生・波形表示。M4Aは1音声トラック、mono / stereoのAAC-LC・ALAC（システムが復号できるもの）。 |
| 入力動画 | .mov / .mp4 / .m4v | screen.bmp材質・指定材質または背景へ投影。利用可能なデコーダーに依存。 |
| ポーズ | .vpd | 指ポーズライブラリへ読み込み。左手・右手・両手・選択ボーンへ適用。 |
| エフェクト | .fxdayo | 既知ソース用Metal adapter、または条件を満たす限定原文実行profileで利用。 |
| DoF・照明 | .dofvmd | v1〜v3。DoF、照明4種のキー、v3のボケ量係数キーを扱う。保存内容に合わせて形式を選択。 |
| プロジェクト | .vmdviewer | モデル・テクスチャ・音声・投影動画・設定を同梱するZIP。旧ディレクトリ形式も読み込み可能。 |
| 効果割り当て | .json | PMX単位またはプロジェクト単位で移植。材質、画像、コントローラの対応を照合。 |

動画の音声ミックスは対応仕様に含めず、動画書き出しの音声入力はシーンに読み込んだWAV / M4Aです。VPDは読み込み・適用用で、VPD出力を記載したものではありません。

## 3. 再生・時計

| 対象 | 仕様 |
| --- | --- |
| VMD時刻 | 30 frame/s基準。描画周期とは独立し、小数フレームを補間。 |
| 描画設定 | 24 fps固定 / 30 fps固定 / 60 fps上限 / 無制限（画面の更新上限内）。 |
| 物理演算 | 60 / 120 / 180 / 240 Hzの固定ステップ。 |
| 操作 | 再生・停止、コマ送り、数値フレーム移動、スクラブ、範囲ループ。 |

無制限再生で範囲をループすると、先頭の全モデルが映った時点で次の姿勢の描画を始めます。描画・物理の設定を切り替えても、VMDの時間軸は毎秒30フレームです。

## 4. 編集・保存

| 機能 | 仕様 |
| --- | --- |
| モデル管理 | モデルを追加・複製・入れ替え・削除。個体ごとに表示・ロック、VMD、配置・倍率、開始オフセット、描画順を設定。行の右クリックで材質単位の表示を切り替え、再生・動画出力に反映。 |
| キー・タイムライン | ボーン / モーフ / カメラの登録・更新・削除、複数選択、移動、コピー・貼り付け、1フレーム挿入・削除、Undo / Redo、音声波形。 |
| ボーン・指・レイヤー | 複数ボーンとXYZギズモ、ローカル／グローバル編集、左右反転。指の握り・開き・親指曲げとポーズの適用率、追加レイヤーの重み・編集先、足接地・腕と衣装の接触補正。 |
| 補間・カメラ | ボーン4 / カメラ6チャンネルのBezier補間編集。独立カメラ1 / 2、透視 / 正投影、VMDカメラと自由視点の切替。 |
| 表情・自動生成 | モーフ値の一括編集、カメラ目線の両目キー生成・校正、ランダムまばたき生成。候補の確認・適用に対応。 |
| 口パク | 日本語5母音のキー生成。音声から仮生成し、歌詞・読みで再解析。手入力・下書きJSON・候補比較・明示適用に対応。外部解析環境は対応条件欄参照。 |
| 保存 | プロジェクトの上書き・別名保存。VMDはボーン / モーフ・フレーム範囲を選択保存。追加レイヤーは誤差検査付きで標準VMDへ合成出力。 |

未登録のボーン・モーフ・IK編集がある場合、保存・書き出しの前に登録または取消が必要です。プロジェクトは素材や編集構造を保持し、通常VMDにはプロジェクト固有の構造をそのまま格納しません。

### Codexとの共有（MCP）

「設定 → 一般 → 外部連携 → Codexとの共有」をオンにすると、同じMac・同じログインユーザーのCodexから、開いている作品に接続できます。同梱のMCPヘルパーをCodexに登録して使用します。共有は起動時にオフです。共有するモデル名やプレビュー画像は、利用中のCodexのモデル処理に渡る場合があります。

| 操作 | 対象と適用条件 |
| --- | --- |
| 照会・比較 | 再生位置、骨・モーフ・登録キー、指定コマの画像、出力前の警告を照会。正面写真からの上半身ポーズ、足滑り、別PMXでの姿勢、カメラの余白を比較。 |
| ポーズ・表情 | 2〜3個のキーポーズ、表情・視線、足IK補正レイヤーを試作。既存ボーン・モーフキーは時間差を保って移動。衝突した一括移動は全件保留。 |
| 登録・取り消し | ポーズ、カメラ、材質表示は個別に変更を許可。確認した候補を一括適用し、1回のUndoで戻す。カメラの区間補正は最大3キー。 |

## 5. 描画・物理

| 機能 | 仕様 |
| --- | --- |
| 描画方式 | Metal、ToonShader（軽量）、ToonShader（高品質）。内部解像度は互換・1/1〜1/2から選択。高品質はHDR中間描画、PMXエッジ、Diffusion、RimLight、Bloom、AO、Tonemapper。 |
| AA・被写界深度 | OFF／FXAA／TAA／MetalFX。HQのDoFはtype2とLiteDOF HC（type1）を選択。焦点・F値・ボケ量の調整、ボーン追従、キー登録に対応。 |
| 材質・照明 | 標準／PBR／Rhinestone、Holographic、画像・演算ノード。HQでは陰色画像、リムマスク、発光面の色の保持、個体別の局所光を設定。背景・環境光・平行光源の色と光の方向をキー編集。 |
| スキニング・モーフ | BDEF1 / 2 / 4、SDEF、QDEF。頂点・UV・材質・ボーン、グループ / フリップ、物理インパルスモーフを評価。 |
| 物理 | Bullet 3.25ネイティブ / 2.75互換モード。Joint 0-5、TriMesh / Rope軟体、外部親、モデル間衝突。ON / OFF・リセット、重力・応答調整。 |
| 動画・表示補助 | 動画の開始位置・offset・loop・投影先を設定。グリッド、ワイヤーフレーム、ボーン・剛体・ジョイント表示、編集UIを隠す全画面。左下の操作ガイドは編集モードに追従。 |

2.75互換モードでも演算には同梱のBullet 3.25を使用します。Holographic／RhinestoneはMetalによる近似で、Holographicの半透明部分・鏡面内部への効果は対象外です。

専用処理はMobFesPenlight_3、MMDayo_SSR、beam、Cracker、ikHolographicに対応。原文実行はHQ・FrameTime・透視投影・不透明出力などの条件を満たす構成で利用できます。[.fxdayoの対応範囲](../fxdayo/README.md)

## 6. 動画書き出し

| UI上のコーデック | コンテナ | 背景・アルファ |
| --- | --- | --- |
| H.264 | MP4 / MOV | 不透明 |
| HEVC | MP4 / MOV | 不透明 |
| ProRes 444 | MOV | アルファなし（ap4h） |
| ProRes 4444 | MOV | 透過 / 背景色を選択（ap4h） |
| ProRes 4444 XQ | MOV | 透過 / 背景色を選択（ap4x） |

「ProRes 444」はApple ProRes 4444をアルファなしで保存するアプリ内の表示名です。

| 項目 | 仕様 |
| --- | --- |
| 解像度 | 1280×720 / 1920×1080 / 3840×2160。カスタムは縦横とも2以上の偶数（GPU・エンコーダーの制約内）。 |
| 出力fps | 23.98（24000/1001）/ 24 / 29.97（30000/1001）/ 30 / 59.94（60000/1001）/ 60。カスタム1〜240 fps。 |
| 色・音声 | SDR Rec.709、writer入力は8-bit BGRA。音声を含める場合はシーンのWAV / M4Aを指定範囲でtrimし、AAC-LC 48 kHz / 256 kbps設定で格納。 |
| 評価・操作 | VMD 30 fps基準の区間指定。専用オフスクリーン評価で全物理ステップを計算。進捗・取消・上書きに対応し、保存確定後に完了表示。 |
| 合成素材 | HQの単一露光で対象モデルを選ぶと、完成動画はMOVに固定。パッケージ `.vmdpasses` に完成MOV、人物別16 bitグレーPNG、線形深度EXR、時刻対応表をまとめる。 |
| 保存先 | ローカル・NASへ書き出し。保存先フォルダの一時ファイルから確定。対応コーデック・寸法は実行環境で判定。 |

透過出力ではMetalFX選択時にTAAを使用します。透過に対応しない効果は書き出し前に通知します。NASへの保存確定時の同名競合は、保存先が対応するファイル操作に依存します。

## 7. 制限・対応条件

| 項目 | 条件 |
| --- | --- |
| 互換性 | MMD / MMEの厳密な画像・物理一致は未検証。PMX 2.1の全機能対応ではなく、PMXの編集・再書き出しには未対応。追加UV1〜4は作者指定の輪郭用法線に使える。追加UV2〜4の任意シェーダーへの受け渡しには未対応。 |
| エフェクト | 任意の.fx / .fxdayoを無条件に実行する仕様ではない。既知のSSR・beam・Cracker・Holographic等も版・構成条件がある。透過出力を拒否する効果がある。 |
| 口パク解析 | 仮生成はwhisper.cpp＋多言語モデル＋MFA、再解析はMFAと日本語モデルを別途設定。自動ボーカル分離・モデル自動取得は未実装。全母音を試聴・確認して採用する。 |
| 描画性能 | モデル数・頂点数の保証上限は未規定。表示fpsは機種、解像度、モデル数、物理・エフェクトによって変わる。測定条件は末尾を参照。 |
| 保存と回復 | 確定済みの編集をローカルに世代保存。既定は1分。手動保存は動画本体を含み、自動保存は参照先と投影設定を記録する。動画を移動した場合は回復時に再指定または解除。 |

自動口パクの基準環境はMFA 3.4.3と日本語モデルです。原音と分離音の開始時刻・全長の一致は利用者が確認します。分離音ファイル、whisper.cpp / MFAの実行環境・モデルはプロジェクトの自己完結保存に含めません。

## 8. データ形式上の上限・補足

| 対象 | 上限・保存仕様 |
| --- | --- |
| VMD codec | ボーン / モーフ / カメラ / 照明 / セルフシャドウ / IKフレームは各20,000,000件。IK状態も1フレームあたり20,000,000件。フレーム番号は0-4,294,967,295。 |
| レイヤーのVMD合成 | 追加生成キー2,000,000件まで。合成誤差検査を通過した候補を保存。物理ベイクではない。 |
| DoF・照明キー | 合算100,000キー、16 MiBまで。照明VMDの取り込み時にも展開後のキー数制限を適用。 |
| VPD | 1ファイル16 MiB / 100,000 recordsまで。UTF-8 / Shift_JISの標準的なボーン姿勢。 |
| プロジェクト | ZIPコンテナv1、manifest schema 55。非表示材質を保存すると最低readerも55。全材質を表示していても、形式54までのv0.58.29では開けない。旧版で使う原本は別名保存で残す。 |

形式上の上限は、その件数・容量での処理速度や実機動作を保証する値ではありません。実用上の上限は入力と機器資源に依存します。
