APPLE SILICON NATIVE · macOS

Apple Siliconネイティブで、MacにMMD制作を。

VMD Viewer for Mac（VvfM）は、Apple SiliconネイティブのMac向けMMD動画制作アプリ。PMXモデルとVMDモーションの読み込みから、動き・表情・カメラの編集、音声付き動画の出力まで。

Windows版MikuMikuDanceを動かす仕組みではなく、Mac向けに開発された別アプリです。

アプリをダウンロード ↗紹介動画を見る ↗

対応環境：M2以降のMac / macOS 14以降Intel Mac・M1のMacは対象外です。

配布ページのZIPを展開して使用します。モデル・モーション・音源は別途必要です。

CREATE ON YOUR MAC

読み込む、調整する、動画にする。

01

PMX・VMDを読み込む

複数のPMXモデルとVMDモーションを組み合わせて再生。キャラクターやステージを配置し、Mac上で動きを確認できます。

02

動きと見た目を整える

ボーン・モーフ・カメラのタイムラインを編集。音声の波形を見ながら調整し、シェーダーや被写界深度で仕上げます。

03

作品を保存・出力する

作業を.vmdviewerプロジェクトとして保存。H.264・HEVC・ProRes形式の動画出力や、VMDの保存に対応しています。

Macの描画技術、Metalを採用。
モデルの描画にはMetal、音声・動画処理にはAVFoundationを使用しています。画質や処理速度は、Mac・素材・設定によって変わります。技術ガイドで仕組みと検証範囲を読む

FIRST STEPS

Apple Silicon MacでMMDを始める

MacでMMDを始める手順：導入からモデル読み込み・10秒の動画出力まで →

  1. 対応環境を確認する

    macOS 14以降、M2以降のMacが対象です。必要なメモリや処理負荷は、素材・モデル数・画質設定によって変わります。

  2. アプリと素材を準備する

    最新リリースからZIPをダウンロードし展開します。初回起動は導入手順を参照。利用許諾を確認したPMX・VMD・音源を別途用意してください。

  3. モデルとモーションを再生する

    PMXと付属テクスチャのフォルダ構成を保ち、⇧⌘Oでモデルを読み込みます。対象モデルを選び、0フレームで⌥⌘OからVMDを読み込み、Spaceで再生します。

  4. 保存して、短い動画を出力する

    ⌘Sで作業を保存。⇧⌘Eで短い区間の動画出力を試し、動きや画質を確認してから作品を仕上げましょう。

BEFORE YOU START

よくある質問

MacでMMD作品は作れますか？

M2以降・macOS 14以降のMacでは、Apple SiliconネイティブのVvfMでPMXモデルとVMDモーションを読み込み、編集・動画出力ができます。Windows版MikuMikuDanceそのものではなく、完全な互換性は保証していません。初めての方向けの導入・操作手順をご覧ください。

Windows版MikuMikuDanceをMacで動かすアプリですか？

いいえ。VvfMはMac向けの別アプリです。MMDで使われるPMX・VMDを読み込みますが、画像・物理演算・エフェクトの完全一致は保証していません。

Intel MacやM1のMacで使えますか？

現在の配布版はM2以降・macOS 14以降が対象です。Intel MacやM1は、この動作対象に含めていません。

XcodeやHomebrewは必要ですか？

配布ZIPを展開して使うため、XcodeやHomebrewのインストールは不要です。初回起動の確認事項はマニュアルを参照してください。

モデル・モーション・音楽は付属しますか？

素材は利用許諾を確認したものを別途用意します。作品の公開や素材入りプロジェクトの共有では、それぞれの規約・クレジット・再配布条件を確認してください。
